# Data / 数据

Current snapshot: 2026-09-24 (upstream `adopted.csv`; `conventions.updatedAt` 2026-09-24). The adopted dataset contains **284 plan × model rows: 265 subscription rows and 19 metered API rows** — 266 rows synced verbatim from upstream `FeiZhuLulu/real-api-pricing` plus 18 local-only GLM Coding Plan global USD rows (Z.ai $18/$80/$168, regenerated by the local `glm_rows()` block). This covers the project's adopted sample, not every plan or model on the market.

These files are the public redacted edition. Original local evidence is backed up outside Git; see [PUBLICATION.md](../PUBLICATION.md) in the upstream repo. 本目录为公开脱敏版，保留数值、来源与取舍记录，原件仅存于 Git 忽略的本地备份。

## Schema (adopted.csv)

`plan_id, plan_name, plan_name_en, billing, price, currency, price_usd, served_model, monthly_tokens, monthly_yi, real_usd_per_mtok, unmetered, promo_until, confidence, chart_tier, source, decision_note, plan_gen, workload`

- `plan_name_en` — international plan name; populated for `kimi_*` and `mimo_token_*` merged CN/global tiers where `price_usd` is the international USD sticker (Kimi $19/$39/$99, MiMo $6–$100) while `price`/`currency` keep domestic CNY.
- `unmetered` / `promo_until` — currently one row: `devin_pro × swe-2` (`unmetered=true`, promo until 2026-10-31). Unbounded quota → `monthly_tokens` empty, `real_usd_per_mtok=0`. Must be re-verified after the promo ends.
- `plan_gen` — plan generation: `v1` = Kimi music-named tiers, `v2` = GLM 老客 tiers, `v3` = GLM 新客 tiers (incl. our global USD rows — same credit scheme).
- `workload` — provenance of `monthly_tokens`: `standard` (÷97/2.5/0.5 mix), `lowCache` (÷85/14.5/0.5, StepFun), `anthropic` (÷Anthropic cache-write mix), `measured` (raw panel/ccusage tokens, no mix applied).

## Conventions

- **Standard workload** (revised 2026-09-23 per `research/standard-token-mix-round2-2026-09-23.json`, 14-sample audit): **97% cache read / 2.5% fresh input / 0.5% output** — was 97.5/2.15/0.35 previously.
- **Low-cache workload**: 85% / 14.5% / 0.5% — second-tier mix for channels that cannot reach ~97% cache in practice (StepFun family).
- **Anthropic workload**: 97% cache-read-priced / 2.5% cache-write-priced / 0.5% output — cache writes substitute the fresh-input share (Anthropic metered API rows + `devin_max × claude-opus-5.5`).
- Kimi/MiMo CNY↔USD merge: domestic and international same-name tiers share one row priced at the international USD sticker.
- Exchange rate: 1 USD = 6.7787 CNY. 1 month = 4 weeks (Kimi month pool = week pool ×5).
- `monthly_tokens` is a **saturation allowance** (pool used up entirely on that model); rows sharing a `plan_id` are alternative uses of one pool, never additive. Scenario rows (GLM peak/mid/offpeak, MiMo day/night, DeepSeek peak/offpeak) are distinct `plan_id`s.
- DeepSeek/OpenCode/Command Code idle-time （闲时） variants are separate scenario points, not averaged.

## DeepSWE files (this repo's addition)

- `deepswe.json` — cached DeepSWE v1.1 leaderboard artifact verbatim (`generated_at` 2026-09-22, 70 configurations).
- `deepswe-configs.json` — extracted per-config records: Pass@1 score, mean cost, median/mean output tokens, steps.
- `model-token-consumption.json` — canonical served-model → DeepSWE mapping: 22 models `available` (median output tokens/task per reasoning tier + default tier) and 39 `pending`.

## Derived outputs (../derived/)

- `task-ranking.json` / `.csv` — task-adjusted ranking of benchmarked subscription rows (138), ranked by effective $/task = price_usd ÷ (monthly_tokens ÷ median output tokens per task).
- `task-ranking-all-efforts.json` / `.csv` — all 291 plan × reasoning-effort combinations.
- `unbenchmarked-models.json` / `.csv` — 146 rows whose model lacks DeepSWE data (`[Pending DeepSWE]`) or is `unmetered`/`metered`.

## Start here / 从这里开始

- [adopted.csv](adopted.csv): current adopted prices, allowances, confidence and rationale; generated by [build_adopted.py](../scripts/build_adopted.py). 当前采用值，不能手改。
- [conventions.json](conventions.json): shared conventions and exchange rate. 部分说明为历史记录，以采用脚本的明确取舍为准。
- [research/](research/): dated evidence (101 files). Historical claims can contradict current decisions; they are not all adopted. 历史证据不等于当前采用结论。
- [raw/](raw/), subscription-quotas*.json, subscriptions.json and claim summaries: historical inputs retained for traceability, not current build inputs. 历史原料保留用于溯源，不是当前主表。
- [SOURCES.md](../SOURCES.md): attribution and third-party license boundaries. 来源署名与许可边界。

Some measurements are estimates, user reports or cross-plan extrapolations. Preserve confidence and decision notes when reusing the data. 缺失分数不补造；推算值不能表述为直接实测。
